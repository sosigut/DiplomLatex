Перечень ключевых слов: Python, JPEG, сжатие изображений, обработка изображений, дискретное косинусное преобразование, квантование, графический интерфейс, тестирование программного обеспечения.

Объектом разработки является программная система сжатия цифровых изображений в формате JPEG.

Целью курсовой работы является разработка программного продукта для сжатия изображений в формате JPEG с использованием языка программирования Python и графического пользовательского интерфейса.

Задачами курсовой работы являются:
\begin{enumerate}
	\item Изучить теоретические основы сжатия изображений в формате JPEG;
	\item Разработать архитектуру программной системы сжатия изображений;
	\item Реализовать алгоритмы обработки изображений, используемые в стандарте JPEG;
	\item Разработать графический пользовательский интерфейс для управления процессом сжатия;
	\item Провести тестирование программной системы и оценить корректность её работы.
\end{enumerate}
